# Подключение Telegram-бота для заявок

Форма на сайте отправляет заявку в Telegram. Пока бот не настроен, форма работает через запасной путь — открывает чат с **@Neytob** с уже готовым текстом заявки. Чтобы заявки приходили автоматически, настрой бота:

## 1. Создай бота
1. Открой в Telegram **@BotFather** → команда `/newbot`.
2. Задай имя и username бота.
3. BotFather пришлёт **токен** вида `8123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Не публикуй его нигде.

## 2. Узнай, куда слать заявки (chat_id)
- **В личку тебе:** напиши своему боту любое сообщение, затем открой
  `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — в ответе найди `chat.id` (число).
  Или просто напиши **@userinfobot** — он покажет твой `id`.
- **В группу:** создай группу, добавь туда бота, отправь сообщение и возьми `chat.id` из `getUpdates` (для групп id отрицательный).

## 3. Пропиши секреты (env-переменные)
Токен НЕ вписывается в код. При деплое на **Vercel** (Project → Settings → Environment Variables) добавь:

```
TELEGRAM_BOT_TOKEN = <твой токен от BotFather>
TELEGRAM_CHAT_ID   = <твой chat_id>
```

Функция `api/lead.js` уже готова — она берёт эти переменные и шлёт заявку боту.

## Локальная проверка (по желанию)
```
npm i -g vercel
vercel dev        # поднимет сайт + /api/lead локально
```
Без бэкенда (обычный статик-сервер) форма автоматически падает в запасной путь — открывает Telegram с готовым текстом на @Neytob.

## Хостинг
Сайт — статический `index.html` + одна функция `api/lead.js`. Идеально ложится на **Vercel** (free): подключаешь репозиторий, добавляешь 2 env-переменные — и заявки идут в Telegram. На других хостингах функцию можно переписать под их формат (Cloudflare Workers / Node) — логика та же: взять токен+chat_id из env и вызвать `sendMessage`.
